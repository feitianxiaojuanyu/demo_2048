# 2048 小游戏（Python 版）

一个零依赖的单文件 2048：运行后自动在浏览器里打开，包含 **棋局** 与 **战绩榜** 两个页面。

## 运行

```bash
python 2048.py
```

- 会自动打开浏览器，命令行里会打印类似 `http://127.0.0.1:55941/#game` 的地址
- 关闭：回到命令行按 `Ctrl+C`
- 只支持 Python 3，不需要安装任何第三方库

## 功能

| 页面 | 内容 |
| --- | --- |
| 棋局 | 4x4 棋盘，方向键 / WASD / 鼠标拖动 / 方向按钮；分数、历史最高、开新局、回退一步、通关提示 |
| 战绩榜 | 最高分、总局数、最大方块、累计步数、前 8 名排行榜、最近 20 局记录、清空战绩 |

## 说明

- 合并逻辑与官方 2048 一致：同值相邻相撞合并、单次移动不可连锁合并
- 战绩由 Python 写入同目录的 `2048_stats.json`，换浏览器、清缓存都不会丢
- 页面用本地 HTTP 服务提供，只监听 `127.0.0.1`，不对外网开放

## 文件

- `2048.py`：全部代码（服务端 + 内嵌页面）
- `2048_stats.json`：首次玩后自动生成的战绩文件
